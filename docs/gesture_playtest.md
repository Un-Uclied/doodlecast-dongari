# 패턴 입력 플레이 테스트

F5로 기존 테스트 맵을 실행하거나 `scenes/test_scene.tscn`을 열고 F6으로 실행한다.

- 좌클릭을 누른 채 화면 어디에나 `—`, `|`, `∧`, `V`, 별, 소용돌이를 한 획으로 그리고 놓는다.
- 독립 테스트 맵에서는 화면 위쪽에 인식 결과와 후보의 오차가 표시된다. 오차는 낮을수록 비슷하며 확률이 아니다. 실제 전투에서는 이 수치 대신 적중·처치 수를 표시한다.
- 반대쪽 끝에서 시작해도 같은 기호로 인식한다. 그리는 동안 WASD 이동과 Shift 대시를 사용할 수 있다.
- 우클릭 또는 Escape로 현재 획을 취소한다. 포커스 상실·창 밖 이탈·창 크기 변경·일시정지에도 취소한다.
- 사망하면 그리기가 중지된다. F5/F6으로 다시 실행한다.

꺾인 선은 대칭인 `V`·`∧`뿐 아니라 한쪽 팔이 짧은 체크 표시 `✓`와 좌우로 뒤집힌 체크도 인정한다. 아래로 꺾이면 `V`, 위로 꺾이면 `∧`에 해당한다. 시작하는 쪽과 약간의 기울기·손떨림은 허용한다.

별은 선이 교차하는 한붓그리기 오각별이다. 다섯 선을 연속해서 그린 뒤 시작점 근처에서 마무리한다. 시작 꼭짓점과 그리는 방향, 기울기는 자유롭다. 가로세로 비율과 꼭짓점이 조금 불규칙하거나, 끝점이 시작점에서 조금 벌어지거나 넘어가도 인정한다. 한 변을 통째로 생략한 모양은 인정하지 않는다. 속이 빈 외곽선 별도 별 패턴으로 인정한다. 적 머리 위의 아이콘도 같은 한붓그리기 모양이다.

소용돌이는 약 1~3바퀴 감기는 나선을 그린다. 시계·반시계 방향, 안에서 바깥 또는 바깥에서 안으로 그리는 것을 허용한다. 단순한 원은 소용돌이로 인정하지 않는다. 새 두 기호에도 동일한 최소 크기 설정을 적용한다.

## 최소 그리기 크기 조절

`scenes/gestures/gesture_canvas.tscn`을 열고 **Canvas** 노드를 선택한다. Inspector의 **Min Stroke Size Percent**를 조절한다. 기본값은 **6%**이며, 값을 높일수록 크게 그려야 한다.

그린 모양의 가로·세로 중 **긴 길이**가 화면의 짧은 변에서 차지하는 비율을 검사한다. 예를 들어 화면이 1280×720이면 10%는 72px, 20%는 144px다. 최소값보다 작으면 모양 비교 전에 인식을 거절한다. 창 크기가 바뀌어도 화면에 대한 비율은 유지된다.

수정 후 저장하고 다시 실행한다. 실행 중에는 Remote 씬 트리의 `GestureCanvas/Canvas`에서 같은 값을 바꿔 바로 비교할 수도 있다.

## 패턴 수정과 추가

`resources/patterns/`의 각 `.tres`를 Inspector에서 연다.

- `id`: 전투 코드가 사용할 고유 이름. 모양만 바꿀 때에는 유지한다.
- `display_name`: 테스트 화면에 표시하는 이름.
- `samples`: 허용하는 모양의 점 배열. 화면처럼 +Y는 아래쪽이다. 각 배열이 한 획의 예시이며, 점 사이를 직선으로 잇는다. 절대 위치와 균일한 크기는 인식에 영향을 주지 않는다.
- `closed`: 별처럼 시작점으로 돌아오는 모양. 켜면 마지막 점이 시작점에서 모양 크기의 35% 안에 있어야 하며, 시작 위치를 바꿔 가며 비교한다. 예시도 닫힌 궤적으로 기록한다.
- `rotation_invariant`: 모양이 회전해도 같은 패턴으로 인정한다. 별·소용돌이에 켜고 가로·세로·꺾인 선은 끈다.
- `max_error`: 허용 오차. 높이면 느슨해지지만 다른 모양도 인정할 위험이 커진다.

새 패턴은 기존 리소스를 복제해 ID와 예시를 수정한 뒤 `resources/patterns/catalog.tres`의 `patterns`에 등록한다. `ambiguity_margin`은 1위와 다른 패턴의 2위 오차가 얼마나 차이 나야 하는지 정한다. 리소스를 바꾼 뒤 게임을 다시 실행한다.

입력·화면 표시는 `scripts/gestures/gesture_canvas.gd`, 모양 비교는 `gesture_recognizer.gd`에 분리되어 있다. 이후 전투는 `GestureCanvas/Canvas.gesture_finished(result, started_at_usec, completed_at_usec)` 신호를 연결하면 된다. 성공 시 `result.pattern_id`가 채워지고 실패 시 빈 ID를 반환한다. 시각은 `Time.get_ticks_usec()` 기준이다.

현재는 여섯 기호와 결과 표시를 구현했다. 예시를 손으로 기록하는 편집 도구와 공격·카운터·즉사기 취소, 여러 획 입력은 아직 추가하지 않았다.

자동 검증:

```powershell
& 'C:/Users/user/Desktop/Godot.exe' --headless --path . --script res://tests/test_gesture_recognizer.gd
& 'C:/Users/user/Desktop/Godot.exe' --headless --path . --script res://tests/test_gesture_tolerance.gd
& 'C:/Users/user/Desktop/Godot.exe' --headless --path . --script res://tests/test_gesture_input.gd
```

관대한 판정의 회귀 테스트는 비대칭 체크, 별의 전 방향 회전, 불규칙한 꼭짓점·비율·끝점과 손떨림을 조합한다. 원·다각형·낙서·미완성 별을 거절하는지도 함께 검사한다. 실제 손입력은 플레이 테스트로 계속 조정한다.


회복 아이템 위 노란 하트 문양을 한 획으로 그리면 체력 1을 회복한다. 시작점·그리는 방향·회전은 자유롭고, 넓고 뚱뚱하거나 둥근 하트와 얕은 홈도 허용한다. 위쪽 두 봉우리 사이의 홈 하나는 유지해야 하며, 원·타원·삼각형·네모나 홈이 여러 개인 별을 하트로 받지 않는다.
